# 八個技能 × 十二種怪 · 量出來的克制關係

這一份不是設計稿，是**量測結果**。兩支工具跑出來的：

```bash
.venv/bin/python tools/skills.py            # 技能對六隻王
.venv/bin/python tools/skills.py --monsters # 技能對十二種小怪
```

改完平衡就重跑一次，這份文件才不會變成「以前是這樣」。

---

## 技能對王：一次施法削掉幾成血

```
技能        糖果史萊姆      褪影射手      迷霧死神      灰燼灶鬼      墜月法師     糖果屋女巫
閃電         13%       12%       10%        0%        9%        7% 
聖光          0%        0%        0%        0%        0%        0% 
龍捲風        11%       10%       12%        0%       11%        5% 
水牢         13%       12%       10%       13%       16%        7% 
雷鳴         13%       15%        3%        0%        3%        9% 
聖癒          0%        0%        0%        0%        0%        0% 
疾風         13%       12%       12%        0%        9%        7% 
怒潮         13%       12%       12%       13%       16%       12% 

沒有任何技能一次打掉王一半以上的血。
```

**上限是刻意的。** `BossSpec.spell_cap`（預設 0.12）壓住一次非提燈傷害最多
能削掉滿血的幾成。沒有它的時候量到的是：水牢一發打掉灰燼灶鬼 78%、疾風貼著
迷霧死神來回蹭掉 93% —— 技能不是幫你打贏這場戰鬥，是直接跳過它。

元素克制沒有被砍掉，只是**收成的地方換了**：打中弱點會開一個破綻視窗，視窗
裡的傷害翻倍 —— 而提燈不受上限限制。所以技能負責開窗，戰鬥還是要打。

灰燼灶鬼那一整排的 0% 也是刻意的：它身上是紅的，沒被水潑到之前什麼都打不
進去。它自己每 10 秒會冷卻 2.6 秒，所以不帶水系技能不是死路，只是很慢。

## 技能對小怪

```

閃電          死   -4推開      死   -3推開      死      死      死      死      死      死      死      死

水牢          死      死      死     推開      死      死      死      死      死      死      死      死
雷鳴          死      死      死      死      死      死      死      死      死      死      死      死
聖癒         推開     推開     推開     推開     沒事     沒事     推開     推開     推開     推開     推開     推開
疾風         推開     推開     推開     推開     推開     推開     推開     推開     推開     推開     推開     推開
怒潮          死      死      死     推開      死      死      死      死      死      死      死      死

「到妹妹」＝這個技能沒攔住它，它走到葛蕾特那裡了。
```

「推開」是控場技能該有的樣子，不是它壞掉。龍捲風和疾風的價值在於**把人挪
走**，而這款遊戲唯一的輸法是有人走到葛蕾特身上。

鏡子怪對水牢、怒潮都是「推開」而不是「死」，因為它正面免疫 —— 而技能是從
漢賽爾站的地方打出去的，那永遠是它的正面。要打死它得繞背，或者開聖光。

## 一句話版本

| 怪 | 答案 |
|---|---|
| 盔甲怪 | 閃電（護甲直接碎） |
| 鏡子怪 | 聖光（照著的時候正面也打得進去） |
| 隱形怪 | 聖光（現形而且定住） |
| 壯漢 | 龍捲風／疾風（打不退，只能推走） |
| 弓箭手・投石怪 | 走過去打斷蓄力，或聖光讓它閃不掉 |
| 分裂怪 | 任何清場技（小的會補在原地，別在她旁邊打） |
| 泥巴怪 | 水牢／怒潮（泥巴清不掉，只能繞） |
| 自爆怪 | 水牢／怒潮（火藥泡濕就炸不了） |
| 糖果史萊姆 | 雷 |
| 褪影射手 | 光 |
| 迷霧死神 | 風 |
| 灰燼灶鬼 | 水（**必須**） |
| 墜月法師 | 水，並把它引去吃自己的隕石 |
| 糖果屋女巫 | 沒有單一解答 —— 她六種招式都有 |
