## 一、要錄 / 要生的素材

### 1. 真的慘叫聲（優先）
`assets/sfx/scream.ogg` 現在是**合成的暫代品**（10 KB，正弦波疊出來的）。
老師和助教點名要「死掉當下明顯的慘叫」，而這一聲是整局遊戲最被記住的一秒。

- 誰錄都行，手機錄一聲就夠
- 兩秒以內、單聲道、存成 `.ogg`（或 `.wav`，程式兩種都吃）
- 蓋掉 `assets/sfx/scream.ogg` 就生效，不用改程式

### 2. 音樂只有一首
`assets/music/gloom.ogg` 一首撐完主選單、白天、夜晚、王之夜。
表在 `src/gingerbread/view/audio.py` 的 `MUSIC`，多一首就改一行：

```python
MUSIC = {"menu": "gloom", "day": "day", "night": "gloom", "boss": "boss"}
```

最有價值的一首是**王之夜**——現在王出場跟平常的夜晚聽起來一模一樣。

### 3. 八隻小怪還是程式畫的
村民、壯漢、孩子、投石怪、隱形怪、泥巴怪、自爆怪、小分裂怪。
六隻王、鏡子怪、弓箭手、盔甲怪、分裂怪已經有圖了。
（挖洞怪、復活怪、小史萊姆已經整個刪掉，不用生。）

生圖的規格和 prompt 在 `docs/素材需求清單.md`。

## 二、第 3–7 夜的開場動畫

現在有四段：`intro`、`day_1`、`night_1`、`day_2`，都是組員寫的，在
`story/` 底下。第三夜以後沒有動畫，會退回文字卡。

要加的話只有兩步：
1. 在 `story/` 放一支新檔，照 `day_2.py` 的形狀寫（`update(dt)` /
   `draw(surface)` / `finished`）
2. 在 `src/gingerbread/app/cutscene.py` 的 `CUTSCENES` 加一行
   `"day_3": "day_3"`

夜晚的動畫用 `night_3` 這種鍵名，白天用 `day_3`。
